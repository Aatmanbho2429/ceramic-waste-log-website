Installing

macOS

  1. Open the downloaded .dmg file.
  2. Drag Ceramic Waste Log into the Applications folder.
  3. Open it from Applications or Launchpad.

Windows

  1. Run the downloaded …-setup.exe file.
  2. If you see “Windows protected your PC”, click More info, then Run anyway. The installer isn't code-signed yet, but it's the official build straight from GitHub.
  3. Follow the installer, then launch it from the Start menu.

How to use it

From a blank install to your first printed month sheet.

  1. 1

    Create your account

    Enter your details, type the 4-digit code emailed to you, then sign in. Your 14-day trial starts, and the account is tied to this PC.

  2. 2

    Set up your masters

    Add your Series (product series), then your Workers. Reasons come pre-filled with the paper sheet's columns — Karigar, Loader, Bhatthi, Handling, Kachu, Repair, Glazing, Pressure, Sorting, Other — rename or reorder them to match yours. Grades ship as Grade 3 (salvage) and Grade 4 (scrap); add your own if you need to.

    Tip: Settings → Load demo data fills a sample register so you can try everything first.

  3. 3

    Log waste

    On Waste log, pick the reason, then tap the grade button against the worker. Counts update instantly; the − button undoes a mis-tap.

  4. 4

    Or scan barcodes

    Open Scanning sheet, print it (A3 PDF), and put it beside the line. Any USB barcode scanner in keyboard mode works — no drivers to install. One scan records one entry. Reprint the sheet after adding workers or grades.

  5. 5

    Check the month

    The Month sheet shows the register on screen: workers down, reasons and grades across, totals on every edge. Use the date range — it defaults to this month, with a "Last month" preset — and the series filter.

  6. 6

    Reports & export

    Reports gives you totals for the period, a breakdown by reason, the workers with the most waste, and the full entry history. Export as PDF (prints like the paper sheet) or CSV for Excel — use CSV if names are typed in Gujarati, since the PDF only prints Latin letters.

  7. 7

    Back up your data

    Settings shows exactly where the database file lives on this PC. Copy that one file to back it up, or to move the register to another machine.

Frequently asked questions

Does it need internet to work?

Only for signing in, licence checks, and updates. Logging waste and building the month sheet work on the local database file, offline.

Can I use one account on two PCs?

No — one licence is bound to one PC. That binding is what stands in for the licence key.

What happens after the trial ends?

Choose a plan from the Profile screen inside the app to keep going. Your data stays exactly as it was.

Which barcode scanner should I buy?

Any Code 128 USB scanner set to keyboard-wedge (HID) mode — which is the factory default on effectively all of them. No drivers or pairing needed.

Does it run on an Intel Mac?

Not at the moment — the macOS build is Apple Silicon only (M1 or newer).

How do I update the app?

Automatically. Ceramic Waste Log checks for new versions itself and shows a banner when one is ready to install.

Where does my data live?

One SQLite file per PC:

macOS: ~/Library/Application Support/com.aatman.ceramicwastelog/worker-log.db
Windows: %APPDATA%\com.aatman.ceramicwastelog\worker-log.db
